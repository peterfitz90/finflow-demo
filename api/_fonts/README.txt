(Copyright 2023 Adobe, with Reserved Font Name "Source"), licensed under the SIL Open Font License
1.1 (LICENSE-source-sans-3.txt). Modifications: the Latin subset from @fontsource/source-sans-3,
with the OpenType ligature features (liga) removed so that text extracted or searched from a PDF
reads exactly as written ("Staff", not "Staf"), and renamed as the OFL requires for a Modified
